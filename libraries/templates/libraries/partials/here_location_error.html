{% comment %} Location-error partial — rendered when /here/resolve/ receives coordinates it can't use: missing lat/lng, unparseable values, or values outside valid geographic bounds. Returned with HTTP 400. This is deliberately distinct from here_no_match.html. The two used to share a screen, which made debugging hard: "we couldn't read your location" and "there's no library nearby" are completely different failures and should read that way. This partial means the coordinates never arrived in usable form — NOT that the area is empty. The "Find my library" button is still on the page above this result, so the copy points the user back at it to retry. All styling lives in here.html's
